Backups & storage

When DATABASE_URL is configured, complete snapshots of metadata, uploaded PDFs and logos are saved to Neon every 4 minutes while the backend is running. Local data and missing uploaded files are checked for recovery every 2 minutes and when the API is accessed. The last 3 changed snapshots are retained. Intentional admin deletions are preserved, not undone. The JSON download below is metadata only.

Open the Backups tab or sign in to check Neon status.

Download metadata JSON ↓

The admin session expires after eight hours and is invalidated on backend restart. Keep credentials private. A persistent Render disk is strongly recommended: changes since the last successful Neon backup can otherwise be lost on a crash. Scheduled jobs cannot run while the backend is sleeping or stopped. A metadata JSON file is not a complete file backup.
